妥当

3200 の品を 2400〜2666 に固定して使うのは技術的に正しい

根拠 3 本（AMD・Crucial・Micron）を一次資料の原文で確認。

取り下げ 1 件

「GT は 3200 で動かす」（ComputerBase）は根拠なし

実測 2 件（別の実機・この NAS）は 2667。計画の「3200 で学習して失敗」は推測に格下げ。

根拠 3 本（一次資料・原文）

Crucial 公式

速い品を足しても安全・一番遅い物の速度で動く

モジュールを作った会社の公式サポート頁。

原文
Memory is designed to be backward compatible within its generation, so generally speaking, you can safely add faster memory to a computer that was designed to run slower memory. However, your system will operate at the speed of the slowest memory module installed.

RAM Memory Speeds And Compatibility | crucial.com

Micron（部品）

3200 のビン（-062E）は遅いビン全部に yes

Crucial の中身は Micron 16Gb DDR4。データシート Table 151「Backward Compatibility」。

原文と注
Table 151: Backward Compatibility — Component Speed Bin -062E（3200）の行：-125（1600）〜-068E（2933）すべて yes。
Note 2: This condition exceeds the JEDEC requirement… However, JEDEC SPD compliance may force modules to only support the JEDEC-defined value.

注 2 の意味：モジュールの SPD が JEDEC の定義した値に絞る事はある→2400・2666 は JEDEC の標準の段なので問題にならない。

Micron 16Gb: x4, x8, x16 DDR4 SDRAM — Rev. H 8/2021（Digi-Key の写し・PDF 12MB）

取り下げ

「GT の BIOS は 3200 の品を 3200 で学習する」は裏が取れなかった

言っている物中身根拠
ComputerBase（独・レビュー）「8GB の品を UGREEN は 3,200 MHz で動かしている・AMD の公称より速い」部品名なし・BIOS の画面なし＝文だけ
Mighty Gadget（英・DXP2800 GT）BIOS Main の写真「8192MB of DDR4 running at 2667 MT/s」写真あり
この NAS（2026-10-18 17:28）BIOS Main：Total Memory 8192MB・Memory Speed 2667MHz（純正 8GB）自分の機械の実測

→ Crucial が「3200 で学習して失敗」しているのか「2667 で学習して別の理由で失敗」しているのかは分からない。ただし速度を下げる試しは、どちらでも「学習の条件を AMD の公称（2667）の中へ寄せる」向きなので価値は残る。

原文
…einer mit einem 8-GB-Modul belegt ist, das Ugreen mit 3.200 MHz ansteuert, also schneller als AMDs offizielle Spezifikationen…

ComputerBase: Ugreen DXP4800 GT & DXP2800 GT im Test ／ Mighty Gadget: UGREEN DXP2800 GT review

分かっている事
  • Crucial 32GB は 1 枚でも 2 枚でも、どちらの口でもメモリ学習で止まる（再現＝系統的・不良ではない）。純正 8GB は両方の口で起動。
  • GT の公式対応表（機種名で引いた一覧）に Kimtigo 32GB・2666 が載る＝この BIOS は 2666 の SPD の 32GB を学習できる。
  • 同じ核（Picasso）の DeskMini A300M で Crucial 32GB×2（2666 版）＝64GB の実機。Beelink SER3 で 3200 の 32GB×2 が「2666 でしか起動しない」実機。
  • AGESA 1.0.0.7 は AMD の最新。UGREEN は BIOS を配っていない。
分からない事
  • この NAS が Crucial を何 MT/s で学習しようとして失敗しているか（3200 か 2667 か）。
  • GT で 64GB（32GB×2）が見えた実機の型番（reddit の「64GB ECC」は型番なし）。
  • AMD CBS の中の実際の項目（機械を開けないと見えない）。
  • 設定で直る種類の失敗か（信号・タイミングの余裕）、直らない種類か（16Gb のアドレス構成等）＝試すまで分からない。
次の手

BIOS の設定で試す（NJ の手 1 回・60〜75 分・計画は変更なし）

  1. 0AI が NAS を止める（LAN から消える）
  2. 1電源→Ctrl+F12→Enter Setup→Advanced→WatchDog の写真→Ctrl+F1→Crb Advanced→AMD CBS→UMC→DDR4。変える前の各画面を写真（戻す時の正本）
  3. 2組 A＝Memory Clock Speed だけ 1200（＝2400）。値と単位は写真で AI が読んでから選ぶ。他は触らない
  4. 3F10→起動中に Ctrl+F12→Main の Memory Speed が新しい値の写真→UGOS 起動→AI が確認→電源ケーブルを抜いて 30 秒→冷間の起動も通る事
  5. 48GB を外し 32GB「1」を下の段→電源→テレビを見る→ブザー 2 回でも 5 分待つ→起動＝合格
  6. 5合格なら AI が free -m（約 31,000MB＝解けた／約 15,500MB＝16GB 扱い）。失敗なら組 B＝1333（＝2666）、時間が残れば組 C＝1066（＝2133）・2 組まで
  7. 632GB×1 が通ったら 2 枚目を上の段→BIOS と OS の両方で容量→3 回の再起動と memtester
  8. 7通らない時：8GB に戻し、写真どおりに手で元の値へ（F9 は使わない）→F10→UGOS
残る危険 1 つと戻し方（R1〜R4）

最初の F10 の後に 8GB でも起動しなくなる経路は完全には消せない（設定の経路の不具合・単位の読み違い等）。データは HDD にあって無事（BIOS の設定はディスクに触らない）。

段手確度・費用
R1電気を抜いて自動の復帰を待つ（ケーブル抜き 1 分→電源ボタン 10 秒→ケーブル→電源→5 分待つ→Ctrl+F12 で入れたら写真どおりに手戻し）3 割・5 分
R2メモリを一度抜いて挿し直してから R1 をもう 1 回5 分
R3電池（CR2032）を外して出荷の値へ＝完全分解。1 段ずつ写真→AI が次を指す。半田なら R430〜60 分・保証に触る可能性
R4UGREEN の修理（保証内）。その間は PC1 で続ける・HDD は手元に送料・日数

当日の手順（NJ の手・1 画面ずつ・10/18 に見た画面から書いた）

合図「やろう」→ AI が NAS を止める → ここから。所要 60〜75 分。AI とは写真でやりとり（画面を撮って送る→AI が値を読んで次を指す）。10/18 に見ていない画面（AMD CBS の中）は推測で書かず「写真→AI が指す」にしてある。

用意する物
  • テレビ（HDMI）と有線の USB キーボード＝10/18 のまま繋いだままなら OK
  • スマホ（写真を撮って送る）
  • Crucial 32GB 2 枚にテープで「1」「2」と番号を書く（どちらを挿したか記録するため）
  • 裏フタのドライバー（付属品）
  • 続けて取れる時間 45 分以上（日曜 09:30 のような予定をまたがない）
時間の決まり
  • BIOS の中に時間の制限はない：10/18 に 10 分いて勝手に再起動しなかった（WatchDog は既定 Disabled）。ただし他の個体で WatchDog が Enabled だと 180 秒で再起動する報告があるので、画面 3 で Disabled を写真で確かめる。
  • NJ の時間が切れた時（10/18 の「時間切れ」と同じ）：
    ・まだ F10 で保存していない → Esc で上の階層へ戻り、Save & Exit のタブ →「Discard Changes and Exit」＝変えた物を捨てて抜ける。8GB のまま起動する。何も壊れない。
    ・F10 で保存した後 → 必ず画面 10（手で元の値に戻す）までやってから抜ける。途中の値で放置しない。
    ・32GB を挿したまま止めない＝終わる時は 8GB に戻して起動を見てから。
  • 迷ったら手を止めて写真を送る。推測で押さない。
  1. 1電源を入れて BIOS に入る（2 分）：電源ボタン → テレビに何か出たら Ctrl+F12 を連打 → 「Please select boot device」の一覧が出る → Enter Setup を選んで Enter → 青い BIOS の画面（Main タブ）。※出ずに UGOS が起動してしまったら、AI に言って止めてもらい、もう 1 回。
  2. 2Main を写真（1 分）：Total Memory 8192MB・Memory Speed 2667MHz が見える画面。これが「変える前」の記録。
  3. 3Advanced タブ → WatchDog Settings（2 分）：→キーで Advanced へ → WatchDog Settings を選んで Enter → 写真。Disabled なら Esc で戻る。Enabled なら AI に写真を送って指示を待つ（先に Disabled にする）。
  4. 4隠れた項目を出す（1 分）：Advanced タブのまま Ctrl+F1 → 一覧に AMD PBS／Crb Advanced／OEM BIOS VERSION が増える → 写真。
  5. 5Crb Advanced → AMD CBS（2 分）：Crb Advanced を選んで Enter → 一覧の下の方に AMD CBS → Enter → ここから先は 10/18 に見ていない画面。入ったらまず写真→AI が次に選ぶ項目を指す（見込み：UMC Common Options → DDR4 Common Options）。
  6. 6変える前の値を全部写真（5 分）：DDR4 Common Options の中の画面を、スクロールして全部撮る（Memory Clock Speed・Enforce POR・Overclock・DRAM Timing など）。この写真が「戻す時の正本」。まだ何も変えない。
  7. 7速度を 1 つだけ変える（5 分）：AI が写真を読んで「どの項目をどの値に」を言う（本命＝Memory Clock Speed を 1200＝2400 MT/s の意味。画面の数字は半分の表示なので AI が確認してから選ぶ）。他の項目は触らない。変えた後を写真。※「Accept／Decline」の注意書きが出たら Accept。
  8. 8保存して確かめる（10 分）：F10 → Yes → 再起動 → 画面が出たらまた Ctrl+F12 連打 → Enter Setup → Main の Memory Speed が新しい値（2400）になっている写真 → Esc → Save & Exit → Exit（保存せず抜ける）→ UGOS が起動 → AI が ssh で確認 → AI が止める → 電源ケーブルを抜いて 30 秒 → 挿して電源 → 起動すれば OK（冷間の起動も通る確認）。
  9. 932GB を 1 枚挿す（10 分）：AI が止める → 裏フタ → 8GB を外す → 32GB「1」を下の段 → 電源 → テレビを見る（何か文字が出たら写真）→ ブザー 2 回が鳴っても 5 分は待つ → 起動した＝合格（AI が free -m で容量を見る）／5 分たっても画面もネットも出ない＝失敗 → 電源長押し（効かなければケーブル）。
    失敗なら 8GB に戻して画面 1 から、値を 1333（＝2666）でもう 1 回（組 B）。時間が残れば 1066（＝2133・組 C）。2 組まで。
  10. 10通らなかった時：元に戻す（7 分）：8GB に戻す → 画面 1 → 画面 5 の経路で DDR4 Common Options → 画面 6 の写真と同じ値に手で戻す（F9「既定値に戻す」は使わない＝他の出荷値も消える恐れ）→ F10 → UGOS 起動 → AI が確認して終わり。
  11. 11通った時（10 分）：AI が止める → 32GB「2」を上の段 → 電源 → BIOS の Main（Total Memory）を写真 → 抜けて UGOS → AI が容量を見る → その後の再起動 3 回と memtester は AI が後でやる。
キーの早見
  • Ctrl+F12（電源を入れた直後に連打）＝起動メニュー「Please select boot device」
  • Enter Setup＝BIOS に入る
  • ←→＝タブの移動（Main／Advanced／Chipset／Security／Boot／Save & Exit）、↑↓＝項目、Enter＝開く・選ぶ、Esc＝1 つ戻る
  • Ctrl+F1（Advanced タブで）＝隠れた項目（AMD PBS／Crb Advanced／OEM）を出す
  • F10＝保存して再起動（Yes で確定）。F9 は押さない。
  • Save & Exit タブ →「Discard Changes and Exit」＝変えた物を捨てて抜ける（時間切れの時はこれ）

今のメモリを使う路線（買い替えは無し）

  1. 1BIOS の設定で通す（上の次の手）
  2. 2UGREEN に BIOS を出させる：箱の「最大 64GB」と DMI の「32GB」の矛盾・64GB を確認した型番・16Gb 密度の 32GB を通す設定を書面で要請（1 の結果を証拠に・同じ核の DeskMini A300 が 64GB 公式を添える）
  3. 3別の機械で使う（家の守りの 2 台目の機械を買う時に DDR4 SO-DIMM 32GB を受ける物を選ぶ）
  4. 4BIOS を自分で焼く＝最後の手・今は候補に置くだけ
